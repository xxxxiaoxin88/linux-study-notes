## Day5 早上 Shell进阶 循环、判断、函数、数组
### if 判断
[ 条件 ] 测试表达式；-f 文件，-d 目录，-z 空判断
elif 多分支

### for 循环
for i in 集合;do ... done
{1..10} 快速生成序列

### while 循环
条件满足持续执行，注意自增避免死循环

### 函数
func(){ ... }
调用直接写函数名，参数  

### 数组
arr=(值1 值2)
${arr[0]} 取元素，${arr[@]} 全部
## Day5 下午 Shell实战 参数、case、日志脚本、调试
### 位置参数
$0 脚本名，$1 $2 参数
$# 参数数量，$@ 全部参数

### case
适合固定字符串匹配，类似菜单选择

### 日志实战
grep + wc -l 统计匹配行数
exit 非0代表脚本异常退出

### 调试
bash -x 脚本名 或者 #!/bin/bash -x
## Day5 晚上 rsync备份 + crontab定时落地
### rsync
rsync -av 源 目标
-a 归档，保留文件属性；-v 详情；-z 压缩
源末尾带 /：同步目录内部文件
--delete：删除目标多余文件，慎用

### crontab 定时
crontab -e 编辑，crontab -l 查看
格式：分 时 日 月 周 执行命令
适合自动备份、日志统计脚本

### 磁盘查看
df -h 分区使用率
du -sh * 统计目录大小
